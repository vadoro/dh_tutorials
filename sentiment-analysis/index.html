    용어집

    한 줄로 정리한 용어

    용어 옆 회색 글씨는 영어 이름이나 기본값이에요. 코드에 그대로 쓰는 이름은 고정폭 글꼴로 적었어요.

    기본

    감정분석 sentiment analysis · opinion mining
    글에 담긴 감정이나 의견이 긍정인지 부정인지, 얼마나 강한지 재는 방법.
    극성 polarity
    긍정·부정·중립의 방향. 흔히 −1~+1 사이의 점수로 나타내요.
    감정 범주 emotion categories
    기쁨, 슬픔, 분노처럼 감정의 종류로 나누는 방법. 에크만(Ekman)의 기본 감정 6가지(기쁨·슬픔·분노·두려움·놀람·혐오)가 자주 쓰여요.
    분석 단위
    문장, 서평 한 편, 소설 한 장처럼 점수를 매기는 단위. 단위에 따라 결과가 달라져요.

    사전과 규칙

    감성 사전 sentiment lexicon
    단어마다 감정 점수를 매겨 둔 목록. KNU 한국어 감성사전은 1만 4천여 개 표현에 −2~+2 점수를 매겼어요. 이 페이지의 사전은 설명용으로 만든 작은 예시예요.
    부정어 negation
    ‘안’, ‘못’, ‘않다’, ‘없다’처럼 뜻을 뒤집는 말. 이 페이지는 점수에 −1을 곱해요.
    강조어 · 약화어 intensifier
    ‘정말’, ‘너무’는 감정을 세게(×1.5), ‘조금’, ‘약간’은 약하게(×0.5).
    대조 contrast
    ‘하지만’, ‘~지만’ 뒤에 진짜 하고 싶은 말이 오는 경우가 많아 앞은 ×0.5, 뒤는 ×1.5.
    VADER
    영어 감성 사전 + 규칙 방법(Hutto & Gilbert, 2014). ‘but’ 앞은 ×0.5, 뒤는 ×1.5로 계산하고, 합을 합 ÷ √(합² + 15)로 −1~+1에 맞춰요.

    기계학습

    학습 데이터 · 시험 데이터
    사람이 정답(긍정/부정)을 표시한 글. 학습 데이터로 배우고, 배우는 데 쓰지 않은 시험 데이터로 성능을 재요.
    나이브 베이즈 MultinomialNB
    낱말이 긍정·부정 글에 나온 비율로 무게를 정하고, 글 속 낱말의 무게를 더해 판단하는 방법. 낱말끼리는 서로 관계가 없다고 ‘순진하게(naive)’ 가정해요.
    라플라스 스무딩 alpha=1
    모든 횟수에 1을 더해, 한쪽에 한 번도 안 나온 낱말이 확률 0을 받지 않게 하는 방법.
    정확도 accuracy
    맞힌 개수 ÷ 전체 개수.
    혼동 행렬 confusion matrix
    실제 정답과 예측을 줄과 칸으로 놓고 개수를 센 표. 어느 쪽으로 자주 틀리는지 보여 줘요.
    정밀도 · 재현율 precision · recall
    정밀도는 ‘긍정이라고 한 것 중 실제 긍정의 비율’, 재현율은 ‘실제 긍정 중 긍정이라고 맞힌 비율’.

    언어 모델과 감정 곡선

    언어 모델 BERT 등
    많은 글로 미리 학습한 모델을 감정분석 데이터로 더 학습시켜(fine-tuning) 써요. 문맥과 순서를 읽지만, 근거를 설명하기 어렵고 계산이 무거워요.
    NSMC Naver Sentiment Movie Corpus
    네이버 영화 리뷰 20만 개(학습 15만, 시험 5만)에 긍정(1)·부정(0)을 표시한 공개 데이터.
    감정 곡선 emotional arc
    이야기의 문장(또는 구간)마다 감정 점수를 매겨 순서대로 이은 선. Jockers의 syuzhet, Reagan 외(2016)의 연구가 유명해요.
    이동 평균 moving average
    앞뒤 몇 개의 값을 평균 내 들쭉날쭉한 선을 부드럽게 만드는 방법. 창이 넓을수록 큰 흐름만 남아요.

    무엇이 진짜 계산인가요? 감성 사전 점수와 규칙, 나이브 베이즈의 낱말 무게와 예측, 정확도와 혼동 행렬, 이동 평균은 이 페이지 안에서 실제로 계산하고, 파이썬·scikit-learn과 값이 같아요(examples/sentiment_basics.py). 다만 사전(어간 80여 개)과 서평(학습 24개, 시험 8개)은 설명을 위해 만든 작은 예시라서, 정확도 숫자를 일반적인 성능으로 읽으면 안 돼요. 낱말 원형은 어절의 앞부분으로 찾는 단순한 방법(형태소 분석기 흉내)이에요. 언어 모델 장면은 원리를 설명할 뿐 계산하지 않고, 이야기 모양 그림은 개념을 나타낸 그림이에요.
