디지털 인문학 · 데이터 분석 입문

보고, 멈추고, 직접 만져 보는 데이터 분석

디지털 인문학 연구에 자주 쓰는 분석 방법을 짧은 인터랙티브 영상으로 설명합니다. 영상은 아무 때나 멈추고 화면 속 데이터를 직접 바꿔 볼 수 있어요. 영상 아래에는 놀이터, 퀴즈, 용어집이 이어집니다.

  • 자막과 음성 해설
  • 장면마다 직접 해 보기
  • 놀이터 · 퀴즈 · 용어집
  • 수업용 MP4 영상

    수업에서 쓰기

    인터랙티브 페이지를 띄워 놓고 장면마다 멈춰 설명하거나, MP4 영상을 그대로 틀어도 됩니다. 영상에는 자막과 장(chapter) 표시가 들어 있어요.

    인터넷 없이 보기

    저장소를 내려받아 이 페이지의 index.html을 열면 설치 없이 모두 동작합니다. 인터넷이 없으면 글꼴만 컴퓨터의 기본 한글 글꼴로 바뀌어요.

    무엇이 진짜 계산인가요?

    중심성, 군집화, 단어 점수 같은 숫자는 페이지 안에서 실제 알고리즘으로 계산합니다. 설명을 위해 흉내 낸 부분은 튜토리얼마다 따로 밝혀 두었어요.

    DH 튜토리얼 · 새 튜토리얼은 같은 형식으로 계속 추가됩니다. 소스와 만드는 규칙은 GitHub 저장소에 있어요.
