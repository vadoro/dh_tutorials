      퀴즈

      열 문제로 확인하기

      영상에서 다룬 순서대로 나옵니다. 답을 고르면 바로 해설이 나와요.

        용어집

        한 줄로 정리한 개념과 공식

        n은 노드 수, L은 링크 수, k는 한 노드의 연결정도, d(i,j)는 두 노드 사이의 거리입니다.

        재료

        노드 node · vertex
        네트워크를 이루는 점. 사람, 기관, 역, 웹페이지, 단어처럼 분석하려는 대상.
        링크 · 엣지 link · edge · tie
        두 노드 사이의 관계. 친구, 거래, 인용, 함께 등장 등.
        방향 네트워크 directed
        관계에 방향이 있는 네트워크. A→B와 B→A가 다를 수 있어요(팔로우, 인용).
        가중 네트워크 weighted
        링크에 세기(가중치)가 있는 네트워크. 연락 횟수, 거래액 등.

        데이터

        엣지 리스트 edge list
        연결된 두 노드를 한 줄에 하나씩 적은 표. 가장 흔한 저장 형식(CSV).
        인접 행렬 adjacency matrix
        n×n 표에서 i와 j가 연결되면 1, 아니면 0. 무방향이면 대각선 기준 대칭.
        연결 덩어리 component
        서로 경로로 이어진 노드들의 묶음. 끊긴 조각의 개수를 셉니다.

        기본 지표

        연결정도 degree
        한 노드에 붙은 링크 수. 방향 네트워크에서는 들어오는 링크(in-degree)와 나가는 링크(out-degree)를 따로 셉니다.
        허브 hub
        연결정도가 유난히 높은 노드.
        최단 경로 · 거리 shortest path · distance
        두 노드를 잇는 가장 짧은 길과 그 길의 링크 수.
        지름 · 평균 경로 길이 diameter · average path length
        모든 쌍의 거리 중 최댓값과 평균값.
        밀도 density
        실제 링크 ÷ 가능한 링크. 2L ÷ n(n−1) (무방향), L ÷ n(n−1) (방향).
        군집 계수 clustering coefficient
        내 이웃끼리 실제로 연결된 쌍 ÷ 가능한 쌍. 2e ÷ k(k−1), e는 이웃 사이 링크 수.

        중심성

        연결정도 중심성 degree centrality
        링크가 많을수록 중요. k ÷ (n−1).
        근접 중심성 closeness centrality
        다른 모든 노드까지 가까울수록 중요. (n−1) ÷ Σ d(i,j).
        매개 중심성 betweenness centrality
        다른 노드 쌍의 최단 경로 위에 자주 놓일수록 중요. 다리, 문지기 역할.
        아이겐벡터 중심성 eigenvector centrality
        중요한 노드와 연결될수록 중요. 구글 페이지랭크(PageRank)가 이 생각을 발전시킨 것.

        구조

        커뮤니티 community
        안쪽은 촘촘하고 바깥과는 듬성듬성한 노드 무리.
        모듈성 modularity
        무리 안쪽 링크가 무작위로 기대되는 양보다 얼마나 많은지 재는 점수. 보통 0.3 이상이면 뚜렷한 편.
        약한 연결 weak ties
        서로 다른 무리를 잇는 느슨한 관계. 새로운 정보가 이 길로 들어온다는 그라노베터의 이론.

        모델

        무작위 네트워크 Erdős–Rényi
        모든 쌍을 같은 확률로 연결. 연결정도가 평균 근처에 몰립니다.
        작은 세상 네트워크 Watts–Strogatz
        촘촘한 이웃 + 몇 개의 지름길. 군집 계수는 높고 평균 거리는 짧아요.
        척도 없는 네트워크 Barabási–Albert
        새 노드가 인기 노드에 붙는 선호적 연결로 소수의 허브가 생깁니다.
